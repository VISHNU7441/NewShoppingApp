## NewShopping-App
#### The project aims to develop a feature-rich iOS shopping app that enables users to browse products, manage wishlists and carts, and streamline the checkout process with a user-centric and scalable design.


### Description
This iOS shopping app is designed to provide a seamless and intuitive shopping experience. Built with **Swift, SwiftUI, and Combine,** the app allows users to browse products, add items to wishlists and carts, and complete purchases efficiently. It follows the **MVVM architecture** for maintainable and scalable code, integrates **RESTful APIs** for dynamic data, and includes a custom-built image loader for optimized performance. This project demonstrates a strong focus on user-centric design and clean coding practices.
### Features
* **Product Browsing**:&nbsp;View a catalog of products with category-based filtering.
* **Wishlist Management**:&nbsp;Add or remove items from the wishlist with a single tap.
* **Cart Management**:&nbsp;Add items to the cart, update quantities, and remove items.
* **Real-Time Updates**:&nbsp; Use of Combine for reactive state management across views.
* **Custom Image Loader**:&nbsp; Optimized image loading for enhanced performance.
* **Detailed Product View**:&nbsp; Access detailed information for each product.
### Technologies Used
* Programming Language: Swift
* Frameworks: SwiftUI, Combine
* Design Patterns: MVVM (Model-View-ViewModel)
* API Integration: RESTful APIs with async/await for seamless data fetching
* Development Tools: Xcode, Git, GitHub
### Getting Started
#### Prerequisites
* macOS with Xcode installed (Xcode version 12 or later recommended).
#### Installation
1. Clone the repository:
```console
git clone https://github.com/VISHNU7441/NewShoppingApp.git
```
2. Open the project in Xcode:
```console
cd NewShoppingApp
open NewShoppingApp.xcodeproj
```
3. Build and run the app on a simulator or connected device.
